列表 / 详情

顶部标题 + 筛选 chips；详情底部固定操作条

进度与收藏

localStorage 带 moduleId；收藏、看到第几段

搜索与深链

全模块统一搜索；/#/interview/q-rag-01

时间点章节

一条视频切成 3-6 段，点段跳转；进度记到秒

导出备份

一份 JSON 带走全部进度：收藏、看到第几秒

以后加东西，加在哪一层EXTENSION
L1加一条视频（改 JSON + 切章节）2 分钟
L2加一个方向（如「多模态」「评测」）10 分钟
L3加第 5 个模块（如「AI 资讯」「论文精读」）半天
L4加一种新轴（同一批视频换个切法，如「按公司」）1 天
核心抽象：Module = { list, detail, flowItem, schema } —— 新增模块只加目录 + 注册一行，首页 / 搜索 / 我的 自动生效 配套：四模块交互图（8 屏）· 概要设计 v0.3
